# English Pro — English Learning Website

## Как запустить
1. Распакуйте архив.
2. Откройте папку в Visual Studio Code.
3. Установите расширение Live Server (если ещё не установлено).
4. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.

Можно также просто открыть `index.html` в браузере.

## Что уже работает
- Регистрация и вход в демо-режиме.
- Выбор уровня A0–C2 при первом входе.
- Цель занятий на день.
- Дневная и ночная темы.
- Адаптивная вёрстка для телефона, планшета и компьютера.
- Учебный путь из 10 мини-уроков.
- Тесты с проверкой ответов и объяснениями.
- XP и подсчёт завершённых уроков.
- Дни подряд и календарь активности.
- Словарь и избранные слова.
- Профиль и сохранение настроек.
- Сохранение данных в localStorage.

## Важно
Это frontend-демо. Пароли хранятся локально в браузере и не защищены. Для настоящих пользователей, безопасной авторизации и синхронизации между устройствами потребуется backend, база данных и серверная авторизация.
